# Image Search with Pretrained ResNet-18 Embeddings
## Visual search on CIFAR-10 — a summer-research portfolio project

**Author:** Austin (BSc Computer Science + Data Science, University of Sydney)
**Purpose:** a hands-on computer-vision project to support a summer vacation-research
application to Dr Chang Xu's group (machine learning / computer vision, including
visual search). Built November 2026.

## What it does

Given a query image, the system returns the most visually similar images from a
gallery, ranked by cosine similarity of deep embeddings:

1. **Embeddings** — a ResNet-18 pretrained on ImageNet (ONNX, `resnet18-v1-7`),
   with the classification head removed. The 512-d output of global average
   pooling is L2-normalised and used as the image representation. No training
   from scratch; this is transfer learning / representation reuse.
2. **Index & search** — gallery embeddings are stored as a NumPy array and
   searched by brute-force cosine similarity (exact, no approximation).
3. **Baseline** — a 64-d RGB colour-histogram representation, searched the same
   way, so the report can show *why* deep features beat a hand-crafted one.
4. **Evaluation** — Recall@5, Recall@10 and mAP@10 on 500 held-out queries,
   where "relevant" = same CIFAR-10 class as the query (an honest proxy:
   same class is not the same object instance — see `REPORT.md`).

## Results

See `REPORT.md` and `results/results.json` for the measured numbers
(generated by `src/evaluate.py`). `results/demo.html` shows example queries
with their top-5 retrieved images.

## Dataset

CIFAR-10 test split (10,000 images, 32x32, 10 classes). Gallery = first 5,000
test images; queries = next 500 test images (disjoint from the gallery, so a
query can never retrieve itself). Loaded from the Hugging Face parquet mirror
of CIFAR-10 (`uoft-cs/cifar10`, same images/labels as the Toronto release).

## Run it

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
bash run_all.sh          # downloads model + data, extracts embeddings, evaluates
```

Individual steps:

```bash
.venv/bin/python src/extract_embeddings.py   # -> results/embeddings.npz
.venv/bin/python src/evaluate.py             # -> results/results.json, results/demo.html
.venv/bin/python src/search.py --image path/to/query.jpg --top 5
```

## Files

| File | What it is |
|---|---|
| `src/extract_embeddings.py` | Builds the embedding model from the ResNet-18 ONNX graph, loads CIFAR-10, extracts + saves embeddings |
| `src/evaluate.py` | Cosine search, Recall@k / mAP@k, baseline comparison, demo page |
| `src/search.py` | Search the gallery with any image file |
| `REPORT.md` | Short English report: method, results, limitations, what I would do next |
| `requirements.txt` | `onnxruntime`, `onnx`, `numpy`, `pillow`, `scikit-learn`, `matplotlib` |

## What I learned / would do next

- Transfer learning: ImageNet features generalise to a new dataset without any
  fine-tuning, and the gap over a colour histogram is large (see report).
- Evaluation design matters as much as the model: class labels are only a
  proxy for visual similarity, so qualitative examples belong next to the numbers.
- Next steps: fine-tune the backbone on CIFAR-10, try a stronger backbone
  (ResNet-50 / ViT), and replace brute-force search with an approximate index
  (e.g. FAISS) so the gallery can grow to millions of images.
